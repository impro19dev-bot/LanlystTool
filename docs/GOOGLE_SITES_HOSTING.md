# Host Privacy & Support on Google Sites

Files in this folder:

| File | App Store Connect field |
|---|---|
| `privacy-policy.html` | **Privacy Policy URL** |
| `support.html` | **Support URL** |
| `APP_PRIVACY_NUTRITION_LABELS.md` | Fill **App Privacy** questionnaire |

Contact email for both pages: **impro19dev@gmail.com**

## Google Sites (recommended)

1. Create a site (e.g. `https://sites.google.com/view/lanlyst-tool/...`).
2. Add two pages: **Privacy Policy** and **Support**.
3. Insert → **Embed** → **Embed code**.
4. Paste the full HTML from each file (or paste the `<body>` content if the embed strips `<html>`).
5. Publish the site.
6. Copy the published page URLs into App Store Connect:
   - Privacy Policy URL
   - Support URL

### Colors used (matches the app)

- Navy `#1A325F` / `#152A52` / `#1E3A6E`
- Background `#F2F3F5`
- Teal `#1ABC9C`
- Orange `#E67E22`
- Text `#1A2B4A` / muted `#6B7280`

## Alternative

Host the HTML on GitHub Pages, Cloudflare Pages, or any static host and use those HTTPS URLs instead.
